# Generador de códigos QR

Aplicación web estática (HTML + JS) para generar códigos QR. Sin build ni dependencias que instalar.

## Uso local
Abre `index.html` en el navegador.

## Publicar en GitHub Pages
1. Sube estos archivos a un repositorio.
2. Ve a **Settings → Pages**.
3. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Guarda. En un minuto estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
